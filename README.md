### AI apps I've shipped

- **[Ask the Declaration](https://askthedeclaration.com)** — semantic search over America's founding documents for the country's 250th. Retrieval, embeddings, and synthesis all run in your browser. No servers, no API keys. My first production retrieval system. ([code](https://github.com/swapniltamse/ask-the-declaration))
- **[Wiser Bite](https://wiserbite.swapniltamse.com)** — same food, different wisdom. Hybrid RAG where the rules and safety are deterministic and only the voice is generated. Runs on-device with Transformers.js.
- **[Parenting-OS](https://baby.swapniltamse.com)** — local-first, voice-first infant tracker. Logs on-device in ~30ms; the network is background sync, never a requirement.
- **[Momentum](https://momentum.swapniltamse.com)** — a one-button task starter for ADHD brains, built for my wife. No lists, no streaks, no yesterday.
- **[AI Is Not Magic](https://notmagic.swapniltamse.com)** — a plain-language interactive explainer of how AI actually works and where it breaks. Nothing you type leaves the page.
